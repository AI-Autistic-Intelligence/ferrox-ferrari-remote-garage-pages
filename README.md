## Architecture & Features
- **Mission Control Cockpit**: Pit wall engineering console for Scuderia Ferrari built entirely on real public telemetry (OpenF1, Jolpica-F1, Open-Meteo).
- **Zero Mock / Synthetic Data**: Pure genuine Grand Prix telemetry from Austin 2026 / Monza 2024.
- **Client-Side Telemetry Simulation**: Sub-second GPS track maps, speed delta charts, throttle/braking trace integration, DRS zones, and high-frequency telemetry replay.
- **Standalone Static Deployment**: Fully responsive client-side web application hosted on GitHub Pages with zero server dependency.
